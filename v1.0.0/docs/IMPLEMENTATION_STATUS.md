# 초안 구현 범위

## 구현 및 검증 대상

- AC-01: 수직 내러티브, HTML 본문, 일곱 장면 앵커, 출처·검증 상태. 수치 데이터가 없으므로 차트 대신 필요한 증빙을 표시합니다.
- AC-02: CSS 사선 폴더, 선택 시 돌출·요약 변경, 가로 스와이프·드래그·방향키, 독립 리더 URL. 읽기를 방해하지 않는 수평 wheel/A 단축 탐색.
- AC-03: 고정 문단 ID, 한국어 발췌·문단 요약·출처 레일. EN 선택 시 검수 번역 대기 표시.
- AC-04: Archive/Library 분리, 참고문헌 후보 상태, 파일 기반 공개 데이터 어댑터와 정적 읽기 API. 외부 워커 없이 읽기 가능.
- AC-05: 반응형, 키보드·모션 감소·No-JS·직접 URL·Back/Forward·404·인쇄 경로. 상세 검증 결과는 VALIDATION.md 참조.

## 초안에서 의도적으로 단순화한 항목

- WebGL·R3F·GSAP·Lenis 대신 SVG, CSS, 브라우저 기본 스크롤을 사용합니다. 현재 사용자의 선 중심 초안·최적화 요청에 맞춘 선택입니다.
- 폴더→리더는 클라이언트 라우팅입니다. 풀 3D 힌지·공유 카메라·진행률 기반 역방향 개봉 애니메이션은 구현하지 않았습니다.
- 단순 마우스 이동만으로 모드를 바꾸지 않습니다. 에지 호버 프리뷰나 본문 전체 드래그로 서가 전환은 후속 디자인 범위입니다.
- 스크롤 progress는 현재 장면을 가리킵니다. 전체 지도/카메라 스크럽 애니메이션은 없습니다.
- 영어 UI 일부 메타데이터·연구 검증 안내는 원문 또는 영문을 유지합니다. 완전한 연구 번역은 제공되지 않았습니다.

## 자료 또는 실제 서비스가 있어야 완료할 항목

- 실제 연구 원문과 검증된 데이터·통계 그래프·분석 코드·통합 최종 원고.
- 검수된 영어 문단과 원문 revision별 번역 해시·stale 감지 자동화.
- 원본 PDF 다운로드 및 공개 라이선스·개인정보 검토.
- Supabase 인증·RLS·private storage·관리자 수입/게시 기능. 현재는 DB 자체가 없어 RLS 통과를 주장하지 않습니다.
- Oracle 작업자·Night Vision/Foundry 동기화. 현재 사이트는 이를 사용하지 않습니다.
- 공개 도메인의 canonical·sitemap·OpenGraph URL·정식 SEO 공개 설정.
- Safari/iOS·Firefox·실기기 스크린리더·현장 Core Web Vitals 계측.
- Open Design 도구로의 실제 업로드 및 최종 디자인 검수.

사이트 기능의 검증 완료와 위 자료·외부 서비스의 준비 상태는 별개입니다. 공개 배포·게시·외부 계정 변경은 수행하지 않았습니다.
