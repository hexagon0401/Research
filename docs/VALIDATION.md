# 검증 기록 — 2026-10-21

## 실행 환경

Linux / Node.js 24.19.0 / npm 11.9.0 / Next.js 16.4.2 / React 19.3.1. Playwright는 시스템 Chromium을 사용합니다. Safari·Firefox·실기기·스크린리더 검증은 수행하지 않았습니다.

## 설치·빌드·정합성

- `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`: 잠금 파일로 재설치 성공.
- `npm run build`: 페이지와 공개 읽기 API 정적 생성 성공. TypeScript 컴파일 포함.
- `npm run typecheck`, `npm run format:check`: 성공.
- `npm test`: 콘텐츠 정합성 테스트 5개 통과. 출처·문단·주장 ID, 번역 미검수 상태, 지도 범위, 공개 콘텐츠 개인정보 점검.
- 한국어 발췌 6개를 원본 HANDOFF-01과 정규화 비교하여 전부 일치 확인.

## 브라우저 기능

데스크톱 1440×1000과 모바일 390×844에서 Playwright E2E 22개를 실행합니다. 최종 프로덕션 빌드에서 **22개 모두 통과**했습니다.

검사 범위: 일곱 장면, 국가 선택, 개념 노드, 아카이브 검색·필터·정렬·빈 결과, 저자명 검색, 방향키 폴더 선택, 리더 열기·요약·출처 레일·Back, 직접 문단 URL·새로고침, UI 언어 저장, 미검수 번역 폴백, 모션 감소, No-JS 본문 열람, 404, 수평·수직 wheel 구분, A/Escape 복귀, 공개 API·없는 ID·POST 거부.

별도 수동 자동화 점검:

- 375 / 390 / 768 / 1280 / 1440 / 1920px 메인 화면의 EN/KO에서 문서 및 헤더 가로 넘침 없음.
- 메인·아카이브·라이브러리·리더·방법론·소개·접근성 페이지 axe 검사. WCAG 2 A/AA 및 2.1 A/AA 태그에서 위반 0개. 자동 검사 결과이며 완전한 접근성 인증은 아닙니다.
- 한국어 IBM Plex Sans KR 서브셋 로드 및 한국어 화면 시각 확인.
- Desktop / Mobile / Korean 화면 캡처: `docs/previews/`.

## 성능 최적화

- 정적 HTML과 공개 JSON 사전 생성. 외부 DB·워커가 읽기 요청을 막지 않음.
- 실제 DOM 본문과 SVG, CSS 서가 사용. WebGL·지도 타일·상시 프레임 루프 없음.
- Natural Earth 경로를 생성 시점에 변환. d3·topojson은 개발 의존성으로만 사용.
- 외부 폰트 요청 없음. 한국어 전체 파일 대신 Unicode 범위별 서브셋 사용. 한국어 폰트 CSS는 필요한 언어·문서 경로에서 지연 로딩.
- 제목의 Geist 라틴 폰트를 Next.js local font로 사전 로드하여 CSS→폰트의 직렬 요청 지연을 단축.
- IntersectionObserver 기반 장면 추적. 단순 스크롤을 매 프레임 상태에 반영하지 않음.
- 원본 PDF·고해상도 이미지·제삼자 분석 스크립트 다운로드 없음.

측정은 로컬 프로덕션 서버의 Lighthouse 13.5.0 모바일 시뮬레이션입니다. 다른 브라우저 검사와 빌드를 멈춘 뒤 실행합니다. 실사용자 75백분위 Core Web Vitals 또는 INP를 측정한 결과는 아닙니다. TBT는 INP와 구별합니다.

**남은 성능 과제:** 느린 모바일 시뮬레이션에서 LCP 목표를 충족하지 못했습니다. 정식 디자인 이관 시 상단 필수 스타일과 본문 하단의 클라이언트 hydration 경계를 더 줄이고 배포 CDN·실기기 조건에서 재계측해야 합니다. 현재 결과를 실사용자 LCP·INP 목표 달성으로 해석하지 않습니다.

## 재사용 환경 설정

클라우드 환경 초안의 `install_script`에 잠금 파일 설치와 프로덕션 빌드, `start_skill`에 기존 체크아웃 사용·서버 재시작·기능 확인·검사 명령을 저장했습니다. 저장 성공을 확인했으며 환경 게시·새 작업 복원은 수행하지 않았습니다. 환경 설정에서 검토·저장한 뒤 환경을 게시해야 재사용 구성이 활성화됩니다. 웹사이트 외부 배포와는 별개입니다.
