# v2.2.0 — 읽기와 시각 설명이 이어지는 연구

2026-10-22. 기존 배포 Root Directory `v1.1.0/`을 유지하며 package·푸터·변경 기록을 2.2.0으로 갱신했습니다. 기준 main은 `cf46693`입니다. 기존 버전 태그를 덮어쓰지 않습니다.

## 이번 변경

메인 전체를 지정 Paper 바탕으로 통일했습니다. 검정 사이드 패널, 포인터를 따라 이동하는 도형, 논지와 별개로 변하는 배경색을 제거했습니다. 기존 에세이 18개 논지는 순서와 본문을 유지하면서 여섯 흐름으로 묶었습니다. 첫 화면의 실제 지리 기반 지구본과 공유 SVG 설명 영역이 기업·정체성·국가 역량·미중 사례·한국·방법론·종합을 따라갑니다.

스크롤 진행이 지도 초점과 표현 간 전환을 제어하며, 포인터·시간 기반 반복 움직임은 없습니다. 관련 지역의 작은 Signal 그라데이션만 지리적 초점을 보조합니다. 지도 viewport는 선택 지역으로 이동하며 주변 지형을 의도적으로 잘라 보여줍니다. 본문·캡션·출처 링크는 이 viewport 밖의 일반 흐름에 있습니다. Natural Earth 지리 데이터와 기존 보고서의 분석 축을 사용하고, 운항 항적·임의 통계·검증된 인과관계를 발명하지 않았습니다.

Archive에는 실제 연구 13개가 두 선반의 폴더로 놓입니다. Library는 현재 네 참고 레코드를 폴더 또는 책등으로 표현합니다. 원문 미확보 도서는 기록만 열며, 표지·원문을 발명하지 않습니다. 선택 제목·설명, 가로 탐색, 방향키·Home·End, 280ms 펼치기·Esc 취소, 모션 감소 시 즉시 링크, 검색·분류·정렬·선택 복원·일반 목록을 구현했습니다. PDF와 전문을 호버에서 프리페치하지 않습니다.

전역 탐색을 정돈하고, 본문을 가리지 않는 별도 sticky 행에 현재 장·얇은 진행선·펼치는 목차만 배치했습니다. 연구 본문·번역·문단 ID·관련 문단 왕복·PDF·기존 API·Supabase 설정은 보존했습니다. 자세한 시각 결정은 [설계 기록](V2_2_DESIGN.md)에 있습니다.

## 완료하지 못한 검사

Playwright 관리 Chromium을 공식 배포 경로에서 설치해 실행했지만 시작 단계에서 `browserType.launch: Target page, context or browser has been closed`로 종료됐습니다. 브라우저 기반 전체 E2E·화면 폭 행렬·axe·시각 검토·Lighthouse를 통과했다고 주장하지 않습니다. 이번 버전의 스크린샷이나 성능 점수도 기록하지 않았습니다. v2.1.0의 점수와 화면을 재사용하지 않습니다.

대체 경로로 Firecrawl의 기존 운영 사이트 읽기 전용 브라우저 접근을 요청했으나 도구가 승인을 요구했고, 현재 세션의 승인 정책상 실행할 수 없어 차단됐습니다. 원격 브라우저 확인도 수행하지 못했습니다.

추가한 브라우저 회귀 검사는 Paper 바탕·호버 시 지도 고정, 축소 목차, 실제 폴더의 선택·취소·리더 복귀, Library의 미확보 상태, 375·390·768·1024·1440px 양 언어 서가를 대상으로 합니다. 실행 가능한 환경에서 다음을 수행해야 합니다.

```sh
npm ci
npx playwright install chromium
npm run build
npm run start -- --port 3001
# 별도 터미널
E2E_BASE_URL=http://127.0.0.1:3001 npm run test:e2e
AUDIT_URL=http://127.0.0.1:3001 npm run audit:performance
```

기존 Chrome은 `CHROME_PATH`로 지정할 수 있습니다. Safari/iOS·Firefox 실기기, 스크린리더 실사용, 운영 배포 완료와 현장 Core Web Vitals는 이번 실행에서 확인하지 않았습니다. 영어는 기존의 편집 번역·저자 검수 대기 상태이고, 연구 사실·통계 재현 검증을 새로 수행하지 않았습니다.
