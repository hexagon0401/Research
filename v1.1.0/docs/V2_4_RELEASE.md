GSAP 3.15.0, ScrollTrigger, MotionPathPlugin은 메인 장면 근처에서만 로드합니다. 실제 휠 입력량을 단계 수로 취급하지 않고 문서 위치가 진행을 결정합니다. 원문은 HTML로 남으며 중요한 문장을 애니메이션 완료까지 숨기지 않습니다.

중국과 Golden Dome에만 조건부 고정을 사용합니다. 작은 화면과 낮은 화면은 고정을 해제합니다. 중국은 단계별 작은 지도와 하단의 국소 다시 보기를 제공합니다. 탐색·키보드·되돌리기·명시적 단일 재생을 지원하고 사용자 개입으로 재생을 취소합니다. 모션 감소·No-JS·엔진 실패 시 전체 설명과 원문 링크를 보존합니다.

날짜의 일·월·연도·기간 정확도와 원문 위치를 별도 메타데이터로 관리합니다. 사업 제안·철회·공급 서술·저자의 분석을 구분하며, 경로와 재생 시간은 실제 항적·물량·시간 축을 뜻하지 않습니다. 캄보디아의 운송 경로나 부지 경계는 추가하지 않았습니다. 미얀마의 안순→윈난→남산은 S08의 개략 서술입니다.

## 성능과 로딩

초기 HTML에 설명·원문 링크·정적 도식을 제공합니다. 지도 지형은 동일 투영 프레임 안의 네이티브 지연 로딩 이미지이며, 고정 높이 도식만 `content-visibility: auto`로 화면 밖 레이아웃을 생략합니다. 장면 근처에서 GSAP가 측정하기 전에 레이아웃을 활성화합니다. 가변 높이 본문에는 추정 높이를 적용하지 않아 목차·핀·복귀 위치를 보존합니다.

첫 제목의 Geist만 미리 요청하고 IBM Plex는 사용 시 요청해 제목과 CSS의 로딩 우선순위를 지킵니다. `font-display: optional`로 느린 접속에서 뒤늦은 글꼴 교체를 피합니다. 글꼴이 준비되지 않으면 해당 방문에서는 시스템 대체 글꼴을 사용합니다. CSS 인라인 실험은 성능 이득이 없어 적용하지 않았습니다. 초기 전송량은 이 환경에서 약 438KB에서 394KB로 줄었습니다.
