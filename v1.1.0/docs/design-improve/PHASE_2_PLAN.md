## Wireframe

1. Existing hero → compact approved author strip → existing research-path navigation.
2. Three **approved** findings cards, each with claim type, exact source link and the author's existing caution.
3. Full (default) / Quick switch. Quick mode uses ?mode=quick, semantic details, and the same 18 anchors. No-JS shows the full essay. Measure the actual visible word count before labeling it '2 minutes'.
4. Existing sticky diagrams and chapter order remain. Repeated bullets are deduplicated at render time only, preserving data and source text. Verify duplicates across the current step, not just across adjacent array entries.
5. Existing Contents/progress bar gains clearer chapter orientation and measured remaining time; do not create a second competing scroll engine.
6. Source excerpt panels remain inline; only author-approved source selection and labels change. Recruiter/print versions reuse approved findings rather than inventing new claims.

## Why this order

Visitors need authorship and useful source states first. Findings and evidence categories then explain what to read for. Quick mode and section layout variation only follow approval of that hierarchy; otherwise a visual redesign would amplify unresolved content alignment.

## Gates
