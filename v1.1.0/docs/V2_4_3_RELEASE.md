# v2.4.3 — 도식 오류 수정·가독성 보완·72시간 AI 검토

2026-11-02. 기준 v2.4.2 `08f3132`. 배포 루트 `v1.1.0/`과 무료 Vercel·Supabase 구성을 유지한다.

## 수정

- 공항의 임의 가로 표시선을 제거했다. 지점·지명과 지리 도형은 유지하고, 북극 위치 안내 지도는 화면 기준 96px·모바일 72px로 제한했다.
- PCA를 가리던 라벨 전체의 불투명 배경을 없앴다. 글자 뒤의 작은 배경은 남긴다. 여섯 입력 연결이 모인 뒤 두 분석 축으로 이어지는 실제 선을 공통 그리기 마스크로 표시한다. 완료 전·후 스크린샷과 연결선 위치의 실제 Ink 픽셀을 검사한다.
- 기업→국가 도식의 배경 지구본과 확대 동작을 제거했다. 첫 화면의 별도 지구본과 실제 사례 지도는 유지한다.
- 해석 비교 도구를 해당 설명 단계의 고정 그림 아래로 옮겼다. 단계의 10~75%에서 실제 시간·공간→해석 가지를 드러내며, 역방향 스크롤도 같은 상태를 재현한다. 수동 조작은 자동 진행보다 우선하고 언어·크기 변경 후에도 유지한다. ‘스크롤에 맞춰 보기’로 현재 위치에 복귀한다. PCA에서는 비교 도구를 숨긴다.
- 기업 역량 4단계·미국 조달 3단계·방법론 4단계의 반복 항목만 한영으로 다듬었다. 항목의 구분어, PCA 한국어 용어·두 분석 축, 원문 링크 제목과 펼칠 실제 문단 수를 보완했다. 본문 크기·읽기 폭·연구 순서는 유지한다.
- 원문 전사·전문 번역·공개 API·백엔드·미디어는 변경하지 않았다.

## 임시 크롤링

절대 UTC 시작·종료 시각을 `src/config/crawler-review.json`에 한 번 기록한다. 재배포는 기한을 갱신하지 않는다. 요청 시각이 종료 시각 이상이면 `Disallow: /`로 돌아간다. 설정 누락·오류·72시간을 넘긴 설정도 차단한다.

활성 중에는 공개 페이지·PDF·렌더링 자원에 `Allow: /`, `/api/`·`/originals/`에는 `Disallow`를 반환한다. HTML의 `noindex, follow`, 인증 및 저장소 권한은 유지한다. robots 응답은 동적이며 브라우저·CDN 캐시를 금지한다. 다른 서비스가 저장한 정책과 자체 접속 제한까지 해제하는 기능은 아니다.

- 시작: **2026-11-02T07:08:44.000Z** (2026-11-02 16:08:44 KST).
- 종료: **2026-11-05T07:08:44.000Z** (**2026-11-05 16:08:44 KST**).
- 종료 정각에 차단되며, 재배포나 재시작으로 연장하지 않는다.
