# v2.0.0 — 연속된 탐구와 원문 자료실

2026-10-22 (Asia/Seoul). 코드 경로는 Vercel 설정과 호환되는 `v1.1.0/`을 유지하고, package 버전과 Git 태그를 `v2.0.0`으로 기록한다. `v1.0.0/`은 수정하지 않았다.

## 마무리한 이전 작업

- v1.1.1: synthesis 장식 SVG가 본문을 덮던 오류 수정. 명시적 SVG 크기, 144px 상한과 열 경계를 적용했다.
- v1.1.2: 서로 다른 연구 원문 13개를 비공개 보존하고 웹 전사·개인정보 제거 PDF·도표 미리보기·출처 위치를 제공했다. 상세 스크롤 계획을 별도 커밋으로 보관했다.
- 실제 클라우드: 원본 13개와 열람본 13개를 두 비공개 Supabase 버킷에 업로드했다. 원격 SHA-256과 실제 5분 서명 다운로드를 전부 검증했다. 큰 PDF는 6MiB 단위 재개 가능한 업로드로 처리했다. 보존 원본은 읽기 전용이며 Git에 넣지 않았다.

## 구현

`ScrollNarrative`가 챕터 상태와 진행률을 관리한다. 세로 입력은 네이티브 스크롤을 사용한다. 전체 폭 배경·연속 강조선으로 장을 연결하고, 궤도 선과 구체·렌즈 행이 읽기 진행에 반응한다. 포인터 반응은 최대 6px이며 본문·조작 영역을 밀어내지 않는다.

스크롤 위치가 바뀔 때만 단일 rAF를 예약한다. 정지 상태의 지속 애니메이션 루프는 없다. 문서 좌표를 캐시하고 root·각 장·각 행의 크기, 언어, 폰트, 뷰포트 변화에서 무효화한다. 읽기·쓰기 단계를 나누고 모든 픽셀마다 React 상태를 바꾸지 않는다.

지도에는 직접 선택 가능한 노드와 포커스/포인터 미리보기를 추가했다. 좁은 화면은 겹치는 지도 히트 영역 대신 큰 국가 버튼을 사용한다. 프레임워크는 일시 미리보기·클릭 고정·읽기 흐름을 구분한다. 고정한 관점은 스크롤이 덮어쓰지 않는다.

전역 가로 휠 가로채기를 제거했다. A 키는 컨트롤·텍스트 선택·IME 입력 밖에서만 서가를 열고 Escape로 이전 위치에 돌아간다. 시스템 모션 감소를 우선하고, 사용자 모션 감소도 저장한다. 모션 설정 변경으로 읽기 위치가 초기화되지 않는다. JavaScript가 없어도 텍스트·문서 링크를 유지한다.

새 모션 라이브러리·WebGL·사진 배경·센서 수집·유료 서비스를 추가하지 않았다. 기존 연구 발췌·검증 상태·원문 ID를 유지했다. 원문 확보나 도표 복제가 연구 결과의 독립 검증을 뜻하지 않는다.

Linux 클라우드, Node 24.x, Chromium 154, 프로덕션 빌드에서 실행했다.

## 성능

최종 프로덕션 서버에서 다른 빌드·브라우저 검사 없이 Lighthouse mobile을 3회 실행했다. 실제 측정 결과는 아래 기록을 따른다. 실험실 TBT는 사용자 INP와 다르다.

| 1    |   95 |    100 |            100 | 2.71s | 121.0ms |   0 |

성능 중앙값 97점, LCP 중앙값 2.47s, 최악 LCP 2.71s. 모든 실행의 CLS는 0이다. 이는 로컬 실험실 측정이며 운영 환경의 사용자 성능 보장은 아니다.
