# v2.3.0 — 읽기 흐름과 그래픽의 연결

기준: v2.2.0 `a8f5575884c35233d5da6a8bc55436d36b886d04`. 배포 Root Directory는 `v1.1.0/`, 무료 배포·Supabase·공개 API는 유지합니다.

## 구현

- 지도 지형, 지명, 점, 설명선의 계층 분리. 설명선은 명시적 `fill="none"`, 지명은 확대와 독립된 HTML 14px. 좁은 공간은 번호와 HTML 지명 목록으로 전환합니다.
- `@chenglou/pretext` 1.0.0의 `prepare`, `measureNaturalWidth`, `layout`으로 지명과 짧은 편집 연결문의 크기를 측정합니다. 글은 계속 HTML입니다. 언어·폰트 완료·크기 변경 때 재계산하며, 읽기 폭이 부족하면 연결문을 세로로 놓습니다. [공식 API](https://github.com/chenglou/pretext).
- 각 논지가 그림·제목·범례·출처를 함께 소유합니다. 서로 다른 지도 투영을 오랫동안 겹치던 공유 패널을 제거했습니다. 새 지형은 180ms, 지명은 지형 이후 120ms로 나타나며 모션 감소에서는 정적입니다.
- 중국–미얀마·중국–캄보디아는 두 국가 지점을 함께 포함하는 카메라 범위. 경위선은 낮은 대비로 유지합니다.
- 조달·준비자산·소유 구조를 서로 다른 관계도 형태로 구분합니다. 지도는 위치가 논지인 경우에 사용합니다. 도식은 인과 검증이나 실제 계약·운항 경로를 뜻하지 않습니다.
- 기업 역량, 북극/그린란드, 최종 통합은 전체 폭으로 예약한 세 장면입니다. 기업 역량의 지구본만 스크롤에 맞춰 작게 확장됩니다. 그린란드는 북극권 배경과 세부 범위를 분리하고, 세 공항 참고 위치에서 CCCC 제안·입찰 철회와 S08 문단으로 이어집니다. 13개 연구는 연구명·역할·설명·전문 링크로 연결됩니다.
- 본문 데스크톱 18px, 모바일 17px. 원문 발췌·편집 연결·정책 제안·확인 범위를 구별합니다. 전문용어 펼침, 사례당 최대 두 원문 문장의 강조, 연구별 기여 역할, 국가별 동일 축 비교를 제공합니다.
- 목차에는 18개 세부 논지와 현재 질문을 표시합니다. 진행률은 라이브 음성 알림이 아닙니다. 원문으로 떠나는 순간 문단 ID와 화면 오프셋을 보관해 복귀·뒤로 가기·언어 전환의 읽기 위치를 복원합니다.
- 모든 사례 그림이 모바일에도 존재합니다. 점·도형·연결과 연구 가지는 버튼이며, 선택 설명에 초점을 보내고 닫기/Esc로 트리거에 복귀합니다. No-JS에는 같은 내용의 정적 설명과 원문 링크가 있습니다.

## 유지한 설계

밝은 Paper `#e6e8e6`, Ink `#0e131f`, Signal `#0efb2e`, Geist·IBM Plex와 얇은 선은 기존 브랜드 토큰입니다. 여백·글자 크기·상태 대비와 정적 대체 구성은 제공된 디자인 기준에 맞춰 조정했습니다. 새로운 연구 사실·수치·검수 번역은 작성하지 않았습니다. 출처에 서술된 금액·날짜·제안 상태는 독립 검증과 구분합니다.

## 검증 기록

구현 완료 후 운영용 빌드, 원문·PDF·API 회귀 검사와 브라우저·성능 검사를 수행합니다. 이 문단은 최종 결과로 갱신합니다. 아직 실행하지 않은 검사를 통과로 간주하지 않습니다.

로컬 macOS Chromium은 MachPortRendezvousServer `bootstrap_check_in ... Permission denied (1100)`로 시작하지 못했습니다. 이 환경에서 시각 검증이나 Lighthouse 점수를 만들어내지 않습니다. 공개 저장소의 Linux GitHub Actions를 사용해 실제 브라우저 검사를 실행하도록 워크플로를 추가했습니다.
