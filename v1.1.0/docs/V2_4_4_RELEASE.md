# v2.4.4 — 연구 사이트 디자인 개선 통합

2026-11-02. 배포 루트는 `v1.1.0/`, 무료 Vercel·Supabase 구성은 유지한다. 사용자가 디자인 검토 브랜치의 이전 개선을 포함해 main 푸시·운영 배포를 명시적으로 요청했다.

## 구현

- 저자가 제공한 이름·학교·연구 기간·LinkedIn을 단일 config에서 표시하고 About을 주 메뉴에 노출한다.
- 빈 발췌문 수 대신 실제 관련 원문 안내를 제공한다. 기존 설명·주소·공개 보고서 13개는 보존한다.
- 기존 한영 용어 설명과 S06의 Rule of 40 정의를 모은 용어집 및 키보드 목차를 제공한다.
- 모바일 제목의 과도한 줄바꿈, 태블릿 제목·저자·지구본 배치, 원문 펼침 영역의 위계를 정리한다.
- 기존 Paper/Ink/Signal 및 로컬 Geist/IBM Plex를 유지하고 읽기 링크·메뉴의 hover/active/focus 상태를 통일한다. 모션 감소 설정에서 추가 전환은 꺼진다.
- 한영 404 안내와 실제 자료실/메인 복귀 경로를 제공한다.
- 원문·전문 번역·PDF·18개 논지 앵커·공개 API와 기존 GSAP/고정 그림 엔진을 유지한다. 검토 제안에만 있는 새 연구 주장·분류는 게시하지 않는다.

## 적용한 Skill과 프롬프트

요청한 현재 upstream 명령은 스킬 이름이 사라져 실패했다. 원본이 존재하는 커밋 e04409a로 고정한 로컬 소스를 같은 Skills CLI 1.7.4로 설치했고 `skills list`에서 Codex/project 등록을 확인했다. 원본 전체를 읽고 실제 사이트에 맞게 적용했다. 설치 파일·로컬 잠금 파일은 Git에 넣지 않는다. [설치 근거](design-improve/SKILLS_INSTALLED.md)와 [강화한 적용 프롬프트](design-improve/IMPLEMENTATION_PROMPT.md)를 보관한다.

실제 구성은 Next.js App Router·React·일반 CSS다. Tailwind 대시보드라는 가정, 존재하지 않는 보라색 그라데이션이나 기본 폰트 문제를 만들어내지 않았다. 새 라이브러리·외부 런타임 요청·유료 서비스는 추가하지 않았다.

## 검증

이전 작업의 비교 화면·측정은 [디자인 개선 기록](design-improve/redesign/RESULTS.md)에 있다. 최종 운영 빌드·전체 회귀 및 운영 확인 결과는 실행 후 아래에 기록한다. 실제 기기/현장 INP를 검증한 것으로 보고하지 않는다.

검색 noindex와 크롤링 예외 경로, 고정 종료 시각 **2026-11-05 16:08:44 KST**는 유지한다.

### 최종 로컬 검증

- 운영 빌드·타입·포맷 검사 통과. 31개 단위/콘텐츠 검사와 원문·번역 지문·PDF 13개 해시·공개 API/백엔드 잠금 검사 통과. 973개 한영 대응 문단을 보존했다.
- 전체 Chromium 회귀: **238개 통과·34개 환경 조건부 제외·실패 0** (총 272개, 6.0분). 기존 18개 앵커·13개 보고서·원문 왕복·PDF/다운로드·실제 휠/터치·키보드·스크롤 정/역방향·확대 보기·모션 감소·No-JS·좁고 낮은 화면·200% 확대·새 소개/용어집/404 흐름을 검사했다.
- 모바일 Lighthouse 3회 중앙값: **성능 90·접근성 100·권장사항 100**. [회차별 결과](validation/v2.4.4-lighthouse-mobile.json)를 보관한다. 절대 성능 목표 95점은 여전히 미달이며, 감사 명령의 기존 목표를 낮추지 않아 해당 명령은 실패 코드로 종료했다. 기능 회귀 실패와 성능 목표 미달을 구분한다. TBT는 248 / 186.5 / 117.5ms로 편차가 컸으며 중앙값 186.5ms는 기존 v2.4.3 기록 152.1ms보다 높아, 5% 상대 TBT 기준도 충족했다고 보고하지 않는다. 성능 안정화는 후속 보완 항목이다.
- 이전 개선의 16개 화면·언어·모션 조합 및 실제 스크린샷 검토 결과는 디자인 개선 기록에 보관돼 있다. 최종 빌드는 UI 변경 후 별도 전체 회귀를 통과했다. 실제 Safari 기기·화면낭독기 또는 운영 실사용 INP를 검증한 것으로 표현하지 않는다.

운영 확인은 main 푸시 후 아래에 기록한다. 배포 문제가 발생하면 v2.4.3으로 복원할 수 있다.
