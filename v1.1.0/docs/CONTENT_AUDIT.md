## 실제 입력과 요청 범위

실제 접근한 첨부는 사이트 명세와 연구 통합 작업계획 **두 파일**입니다. 사이트 제작 요청을 수행했으며, 작업계획 내부의 별도 최종 보고서·대학 지원 활동 기술서 작성 지시는 수행 범위로 확대하지 않았습니다. 최상위 최신 요청에 따라 선 중심 디자인과 후속 Open Design 이관을 우선했습니다.

원본은 `/workspace/attachments`에서 읽었으며 수정하거나 공개 디렉터리에 복사하지 않았습니다. 아래 별칭은 원본 파일명에 포함될 수 있는 개인정보 노출을 피하기 위한 것입니다.

첨부의 ‘13개 파일, 12개 접근 가능’이라는 표현은 이전 작업계획의 서술이며 현재 프로젝트의 확인 결과가 아닙니다. 이번에는 S00–S12 원본을 열지 않았으며, 특히 S12 HWP 변환을 시도하거나 성공한 것으로 기록하지 않습니다.

## 지리·문헌

지도는 Natural Earth의 퍼블릭 도메인 지형을 `world-atlas@2.0.2`로 가져와 빌드 시 SVG로 변환했습니다. 좌표는 국가 라벨을 위한 개략 지점으로 시설·거래·사건 위치가 아닙니다. 재생성은 `npm run generate:map`입니다.

외부 문헌 후보 `Zero to One`과 `Scale`은 HANDOFF-01 §2의 서술에만 근거하며 직접 열람·외부 대조하지 않았습니다. 전문, 페이지 인용, 미확인 URL을 만들지 않았습니다. 저작권이 확인되지 않은 원본 다운로드를 제공하지 않습니다.
