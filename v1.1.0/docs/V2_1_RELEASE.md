# v2.1.0 — S00 중심의 연결된 연구 에세이

2026-10-22 (Asia/Seoul). 배포 폴더는 `v1.1.0/`을 유지합니다. Vercel Hobby와 Supabase Free 구성, 보존 원본과 기존 공개 PDF의 경로·바이트·해시는 변경하지 않았습니다.

## 구현

메인은 7장 프레젠테이션에서 18개 논지가 이어지는 장문 에세이로 바뀌었습니다. 기업의 생존·정체성에서 국가 역량으로, 미국·중국·한국의 구체 사례를 거쳐 S00의 국가–기업 관계 재정의로 연결합니다. 읽기 시간은 실제 표시 분량으로 계산하며, 관련 연구의 구체 문단과 메인을 왕복할 수 있습니다.

시각 영역은 개념도→세계 지도→별도 북극 지도→통합 연구 가지로 이어집니다. 배경과 지도 층은 스크롤 진행에 따라 변화합니다. 모바일은 본문 사이에 그림을 배치합니다. 강제 스냅·전역 부드러운 스크롤·휠 가로채기는 없으며, 정지 시 지속 rAF 루프도 없습니다. 포인터 이동은 그림에만 최대 5px 적용합니다. 모션 감소·키보드·터치·JavaScript 비활성화 경로를 유지합니다.

자료실 기본 목록은 실제 연구 13개입니다. 한·영 전문 973개 문단을 처음부터 HTML로 제공하고 넓은 화면은 병렬, 좁은 화면은 한국어 기본과 언어 전환을 제공합니다. 한국어 표현은 다시 쓰지 않고 문단·읽기 순서·구두점 배치를 복원했습니다. 기존 문단 별칭, 각주·메모·서식 항목·일부 표·도표 미리보기를 보존했습니다. 관련 핵심 문장은 양쪽 언어에서 강조합니다. 영어는 **편집 번역·저자 최종 검수 전**입니다.

PDF는 전문 아래에서 펼칩니다. PDF.js·워커·CMap·폰트·WASM은 자체 호스팅하며 펼치기 전에는 요청하지 않습니다. 한 쪽씩 렌더링하고 쪽 이동·확대·전체화면·다운로드를 제공합니다. 실패하거나 JavaScript가 없어도 전문과 다운로드가 남습니다. 메인의 연구 링크는 전문을 자동 프리페치하지 않습니다.

## 원문 대조와 범위

- PDF 글자 좌표로 S06 5쪽의 쉼표·괄호·약어 배치를 대조했습니다. S15는 표 셀을 기준으로 양식 라벨과 본문을 분리하고, 실제 페이지에서 확인한 α 글리프를 기록했습니다.
- S14의 개념 스키마·비교·피드백 표를 PDF와 대조해 한·영 HTML 표로 복원했습니다. 모든 이미지 안의 글자를 별도 영문 OCR 전문으로 만들었다는 의미는 아닙니다.
- 13개 문서 모두 원문 블록 참조·번역 지문 해시·누락 문자 검사를 통과했습니다. 문자는 공백을 제외해 비교하며 문서화한 반복 머리말과 α 교정을 반영합니다. 이 검사는 문장의 읽기 순서나 번역 의미 검수 전체를 대체하지 않습니다.
- S03/S13의 서로 다른 원본, 보고서 내 상충하는 175/17.5 billion 수치, S15의 1959/1951 연도 등은 임의로 일치시키지 않았습니다. 단위 검사에 핵심 수치·번역 구간 경계·부정 및 한계 표현 회귀 검사를 포함했습니다.
- 이전 원문 추출 JSON, 원본 바이너리와 기존 개인정보 제거 PDF는 바꾸지 않았습니다. 클라우드 원본 26개 업로드·해시 검증은 이전 v2.0.0에서 완료한 작업이며 이번에 새로 수행했다고 보고하지 않습니다.

## 남아 있는 검수·환경 한계

공식 법령·기관 자료의 외부 요청은 현재 환경의 프록시에서 차단됐습니다. 해당 근거는 사이트에서도 확인 대기로 구분하며, 저자의 해석·원문 주장·독립 확인을 혼동하지 않습니다. 계약 상한과 집행액, 지분과 경영 지배, 투자 제안과 운영 경로를 구분했습니다. 외부 근거의 독립 대조와 저자의 영어 최종 검수는 후속 과제입니다. 연구의 통계·인과 분석을 새로 재현하지 않았습니다.

Safari/iOS·Firefox 실기기, 실제 보조기술 사용과 현장 Core Web Vitals는 미확인입니다. 위 결과는 Chromium 자동화·선별 원본 대조·로컬 성능 측정이며, 모든 환경의 수동 검수 완료를 뜻하지 않습니다.

시각 토큰·콘텐츠·출처·인터랙션 경계는 [Open Design 이관 문서](DESIGN_HANDOFF.md)에 기록했습니다. 유료 번역 API·서버·플랜을 추가하지 않았습니다.
