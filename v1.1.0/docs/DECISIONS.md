# v1.1.0 디자인 결정

- v1.0.0의 Next.js App Router·React·TypeScript·SVG·CSS 구조를 유지했습니다. 새 WebGL 또는 애니메이션 의존성은 추가하지 않았습니다.
- 지정 브랜드인 Paper `#E6E8E6`, Ink `#0E131F`, Signal `#0EFB2E`와 로컬 Geist / IBM Plex Sans / IBM Plex Sans KR를 유지했습니다. 추가 중간색은 브랜드 혼합·투명도입니다.
- Swiss 편집 디자인과 공간형 아카이브를 적용했습니다. Hero 제목과 개념 구체는 독립된 grid 영역이며, 작은 화면에서는 세로로 재배치됩니다. 제목 위로 장식 그래픽을 겹치지 않습니다.
- 본문은 16–20px, 문서 원문은 17–18px, 메타데이터는 용도에 맞는 작은 크기를 사용합니다. 장면은 여백과 대형 제목으로 구분합니다.
- 지도는 Natural Earth 기반의 기존 비교 범위이며 거래·동맹·인과 관계를 추가하지 않았습니다. 국가 선택은 사각 마커·밑줄·텍스트로 표시합니다.
- 개념도는 정상 흐름의 버튼 격자로 바꾸었습니다. 가설과 규범적 경계를 구분하고 기존 설명·출처 연결을 유지합니다.
- 폴더는 CSS 사선 시점·종이층·힌지 효과로 표현했습니다. 360ms 열기 효과는 사용자 입력의 결과이며 Esc 또는 취소 버튼으로 중단할 수 있습니다. 모션 감소 시 즉시 실제 링크로 이동합니다. 단일 WebGL 카메라 기반 연속 전환은 구현하지 않았습니다.
- 선택 폴더는 sessionStorage에 저장합니다. 방향키·Home·End를 지원하고, 수평 탐색은 서가 내부 스크롤만 이동시킵니다. 기존 문서 URL과 No-JS 링크를 유지합니다.
- 전역 기능 아이콘은 `.od-icon`과 `--od-icon-size`를 사용합니다. 브랜드 마크·지도·개념 구체는 독립 크기의 콘텐츠 SVG입니다.
- 공개 범위와 noindex를 유지합니다. 연구 JSON·지도 데이터·원본 계획 발췌문은 수정하지 않습니다. 연구 검증 완료, 수치 재현, 검수 번역을 주장하지 않습니다.

레이아웃·크기·접근성 개선은 첨부 명세와 디자인 기준에 따른 구현 판단이며, 사용자가 별도로 승인한 연구 결과가 아닙니다.
