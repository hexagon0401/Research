# Web research used in implementation

Retrieved on 2026-11-02. Direct MDN/W3C website requests were blocked by this environment's CONNECT proxy. Their public official source files on raw.githubusercontent.com returned HTTP 200 and were read. The inaccessible Wikipedia page was not used as evidence. These are engineering references; art direction is our interpretation of the author's Swiss-design brief.

| Official source read                                                                                                            | Applied lesson                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [MDN Grid layout](https://raw.githubusercontent.com/mdn/content/main/files/en-us/web/css/guides/grid_layout/index.md)           | Place title, author and graphic on explicit tracks; use consistent alignment rather than independent offsets.                                             |
| [MDN text-wrap](https://raw.githubusercontent.com/mdn/content/main/files/en-us/web/css/reference/properties/text-wrap/index.md) | Use balance for short headings. Pretty wrapping costs more work, so long reading text returns to normal wrap.                                             |
| [W3C Understanding non-text contrast](https://raw.githubusercontent.com/w3c/wcag/main/understanding/21/non-text-contrast.html)  | Necessary control/state cues need adequate contrast. Use a strong Ink cue and text/shape changes instead of relying only on a low-contrast bright accent. |

The document bodies were not copied into the site. Reference lessons were translated into native CSS and verified in the browser. A source reference is not a substitute for contrast/interaction testing of this implementation.
