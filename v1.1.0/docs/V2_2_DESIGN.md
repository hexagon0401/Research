# v2.2.0 — 연결된 연구를 위한 시각 설계

2026-10-22. 기준은 원격 main `cf46693`입니다. 사용자가 설명한 최신 버전과 달리 이 커밋의 package와 Git 태그는 2.1.0이지만, 폴더명을 옛 코드로 오인하지 않고 최신 연구·백엔드를 기준으로 작업했습니다. 기존 Vercel Root Directory `v1.1.0/`을 유지합니다.

## 방향과 보존 경계

Swiss editorial / shared paper / material archive. 지정한 Paper `#E6E8E6`, Ink `#0E131F`, Signal `#0EFB2E`, 로컬 Geist·IBM Plex Sans·IBM Plex Sans KR를 보존합니다. 새로운 시각 판단은 사용자 요구와 Open Design의 레이아웃·접근성 기준에 따른 구현 선택입니다.

S00 에세이 18개 논지, 실제 연구 13개, 한·영 전문 973개 문단, 각주·출처·이전 문단 앵커·왕복 링크·PDF·검증 상태를 보존합니다. 연구 JSON·번역·원문·PDF·공개 API·Supabase 권한과 인증 설정은 변경하지 않습니다. 사실·통계·번역을 새로 검증했다고 주장하지 않습니다.

## 메인

- 고정된 Paper 바탕. 검정 패널, 읽기와 무관한 배경색 보간, 포인터 추적 이동을 제거합니다.
- 첫 화면의 실제 지리 기반 지구본과 대형 질문. 기업·정체성·국가 역량에서 미중 사례·한국·방법론·종합으로 이어지는 여섯 흐름을 제공합니다. 18개 기존 논지와 순서는 그대로입니다.
- 하나의 SVG 설명 영역이 본문과 같은 바탕에서 지속됩니다. 스크롤 진행이 지도 초점, 지구본·세계·북극 표현, 가설 도식의 연결선을 제어합니다. 정지하면 추가 프레임을 예약하지 않습니다.
- 도식은 각 사례의 분석 축을 구체적으로 표시합니다. 거래·운송 항적이나 검증된 인과관계처럼 보이는 새 간선을 추가하지 않습니다. 임의 숫자·차트도 없습니다.
- 지역 초점을 보조하는 작은 Signal 그라데이션만 SVG 안에 사용합니다. 시간 기반 반복·배경 wash·호버 패럴랙스가 없습니다.
- 지도는 Natural Earth/world-atlas의 사전 생성 geometry입니다. 지명은 참고 위치이고, 북극 지도의 과거 예시 항로는 이번 설명에서 사용하지 않습니다.
- 모바일에서는 장의 맥락이 바뀌는 지점에 설명과 도식을 정상 흐름으로 배치합니다. 본문·모바일 설명은 16px 이상, DOM 텍스트로 제공합니다.

## 서가

- Archive는 현재 실제 연구 13개를 데이터 어댑터에서 받아 두 선반에 놓습니다. 이전 여섯 개 계획 주제 폴더를 실제 원문 대신 표시하지 않습니다.
- Library는 현재 네 참고 레코드를 사용합니다. 계획 문서는 폴더로, 도서 후보는 제목이 있는 단순 책등으로 표시합니다. 표지 이미지를 발명하지 않고 원문 미확보 상태를 유지합니다.
- 포인터·포커스가 선택을 바꾸고 선택 폴더만 Signal로 돌출됩니다. 펼치기 동작은 280ms이며 Esc 또는 취소 버튼으로 중단할 수 있습니다. 모션 감소 설정에서는 실제 링크로 즉시 이동합니다.
- 키보드 방향키·Home·End, 모바일 가로 레일, 검색·필터·정렬, 선택 복원, 일반 목록과 No-JS 링크를 제공합니다. 많은 자료를 한 카드 격자에 모두 밀어 넣지 않습니다.
- 첫 화면이나 폴더 호버에서 전문·PDF를 프리페치하지 않습니다. 기존 리더와 PDF 지연 로딩은 그대로입니다.

## 탐색과 상태

전역 헤더는 브랜드·Archive·Library·추가 메뉴·EN/KO로 정리합니다. 메인에서는 얇은 진행선과 현재 장만 남는 별도 sticky 행이 자기 공간을 차지합니다. 상세 목차는 열 때만 보이며 Escape·선택 후 닫기·포커스 복귀를 제공합니다. 인터페이스 언어 전환은 기존 논지 내 읽기 위치를 보존합니다.

## 구현 파일

- `src/app/story.css`: 스크롤 문서·그래픽·서가·반응형·인쇄.
- `src/components/essay-experience.tsx`: 장면 상태, 진행 표시, 목차, SVG 설명.
- `src/components/material-shelf.tsx`: 실제 자료 어댑터와 폴더·책장 탐색.
- `src/visuals/story.ts`: 시각 표기·짧은 책등 이름. 연구 원문과 별개.
- `src/visuals/atlas.json`: 사전 생성 지리 geometry. `node scripts/generate-visual-atlas.mjs`로 재생성.

새 WebGL·애니메이션 엔진·외부 서비스·유료 API는 추가하지 않습니다. 저사양과 모션 감소 환경에서 같은 문서·자료 접근을 보존합니다. 실행한 검증과 한계는 V2_2_RELEASE.md에 별도로 기록합니다.
